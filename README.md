# Pub Vidéo Studio

Appli web qui crée des vidéos publicitaires verticales (TikTok / Reels / Shorts) pour des entreprises, selon leur métier.

1. Choisir le métier du client (27 métiers prêts + « Autre métier »)
2. Copier / envoyer le message qui liste tout ce dont tu as besoin (photos, logo, contacts…)
3. Remplir les infos, ajouter les photos et le logo, choisir le nombre de vidéos (1 à 5)
4. Télécharger les MP4 (1080×1920, 30 i/s, musique générée libre de droits)

- 100 % dans le navigateur : rien n'est envoyé sur un serveur.
- À utiliser dans **Google Chrome ou Microsoft Edge** sur PC (export MP4 via WebCodecs).
